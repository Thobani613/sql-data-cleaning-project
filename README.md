# SQL Data Cleaning Project

## Overview

End-to-end data cleaning project using PostgreSQL and VS Code.
Dataset: Customer Personality Analysis (Kaggle) — 2240 records.

## Project Structure

- `sql/` — All SQL scripts
- `data/` — Raw data (not tracked in Git)
- `screenshots/` — Query results and outputs

## Tools Used

- PostgreSQL 18
- VS Code + SQLTools
- Git & GitHub

## Steps

1. Created staging table with TEXT columns
2. Imported 2240 rows via COPY command
3. Data cleaning in progress...
